# 가설: E·S·G 개별 점수가 통합등급 산출에 미치는 영향(가중치)

담당: MinjuKim22

## 1. 가설

KCGS ESG 통합등급이 E(환경)·S(사회)·G(지배구조) 중 어느 요소에 더 큰 가중치를 두어 산출되는지 확인한다.

## 2. 필요 데이터

| 데이터 | 출처 | 상태 |
|---|---|---|
| 기업별 E·S·G 개별등급 + 통합등급 | KCGS | 확인 필요 (세부 하위지표 점수 포함 여부가 핵심) |

## 3. 검증 방법 (참고)

- KCGS가 실제 산출 가중치를 공개하지 않을 가능성이 높으므로, 통합등급(순서형) ~ E등급 + S등급 + G등급의
  순서형 로지스틱 회귀로 '드러난 가중치(revealed weight)'를 근사 추정하는 방식을 검토
- 이는 KCGS의 실제 내부 가중치가 아니라 공개 데이터 기반 통계적 근사치임을 명확히 표기할 것
