## 1. 원 가설

ESG펀드가 보유한 채권 발행기업의 신용위험이 실제로 상승(등급 강등·스프레드 확대 등)할 때,
그 영향이 펀드의 실제 성과(기준가·수익률)에 반영되는지를 검증한다.

포트폴리오 리스크 스코어 = Σ (보유종목 비중ᵢ × 종목별 리스크스코어ᵢ)

### 필요 데이터 (원 가설 기준)

| 데이터 | 출처 | 상태 |
|---|---|---|
| 채권 거래량·수익률 | KRX Open API (`bnd_bydd_trd`) | ✅ 확인 완료 |
| 재무제표·부도/회생 이벤트 | DART Open API | ✅ 확인 완료 |
| 펀드 자산구성내역 | FUND DART | ❌ 확보 불가 (막힘) |
| 펀드 기준가(NAV)·수익률 | FUND DART / 제로인 / 에프앤가이드 | ❌ 확보 불가 (막힘) |

펀드 관련 두 데이터는 끝내 실제 소스를 구하지 못해, `esg_fund_credit_hypothesis.ipynb`
(로컬 `C:\hewon\Team_project`)에서는 합성(시뮬레이션) 데이터로 파이프라인만 시연해둔 상태.
**신용위험 사다리(정상→위험징후→신용등급하락→부도) 자체는 DART 실데이터**이고, 합성인 건 어느
펀드가 어느 기업을 얼마나 들고 있는지·기준가뿐 — 이 구분을 헷갈려서 한 번 폐기했다가 되살린
해프닝이 있었음(과정은 원본 세션 기록 참고).

## 2. 재정의한 가설 — ESG등급이 신용위험과 실제로 연결되는가

### 데이터

| 소스 | 내용 | 표본 | 실제/합성 |
|---|---|---|---|
| KCGS ESG등급 | ESG·환경(E)·사회(S)·지배구조(G) 등급 + 등급조정 이벤트 | 1,091개사 (2025) | 실제 |
| 신용위험 사다리 | 정상→위험징후→신용등급하락→부도, 부채비율·유동비율·자본총계 | 3,806개사 | 실제 (`credit_stage_panel.csv`) |
| 조인 결과 | 두 소스를 종목코드로 조인, 등급없음 제외 | 1,025개사 | - |

### 검증 방법

1. KCGS ESG등급(전체·E·S·G) ↔ 신용위험 단계·리스크스코어 순위상관(Spearman), 카이제곱
2. 기업 규모(자본총계) 교란 확인 및 로지스틱회귀로 통제
3. KCGS가 실제 공시한 '등급조정' 이벤트(연중 발생한 거버넌스·사회 리스크로 인한 하향 조정, 53개사)를
   교차 검증 신호로 사용

## 3. 검증 결과

**핵심 발견 — 서로 독립된 두 실제 데이터 신호가 같은 방향을 가리킴**: "ESG등급이 높을수록 신용위험이
낮다"는 단순 가설은 지지되지 않았고, 오히려 반대 방향의 유의한 상관이 반복 관찰됨.

- 우량군(A등급 이상) 위험징후 비율 44.2% vs 비우량군(B+이하) 35.3% (오즈비 1.45, 카이제곱 p=0.017)
- ESG등급 순위상관 vs risk_score: r=0.083, p=0.0077 (환경 r=0.107 p=0.0006, 사회 r=0.073 p=0.019 모두 유의;
  지배구조만 비유의 r=0.048 p=0.126)
- ESG등급은 기업 규모와 강하게 상관(r=0.64, p<0.0001) — 대기업 편향 구조. 다만 로지스틱회귀로 규모를
  통제한 뒤에도 ESG등급 계수는 여전히 유의하게 양(+) (+0.188, p=0.0001) — 규모 편향만으로 완전히
  설명되지 않음
- KCGS 실제 등급조정 이벤트(53개사)에서도 재현: 조정받은 기업의 ESG등급이 오히려 유의하게 더 높음
  (Mann-Whitney p<0.0001~0.01), 조정 안 받은 축으로 교차검증해도 동일 방향
- 심각 신용사건(등급하락·부도, n=10)은 표본이 너무 작아 결론 불가. 그중 2건(HD현대미포·HD현대인프라코어)은
  계열 개편으로 인한 '폐업' 오분류 의심 — 데이터 품질 이슈로 별도 플래그

상세 통계·차트·해석은 `ESG등급_신용위험_EDA_정리본.docx` 참고.

## 3-1. 후속 EDA ① — E·S 등급 세부 분석 (2026-08-24)

기존 결과("우량군 위험징후 44.2% vs 비우량군 35.3%", "지배구조만 비유의")를 이어받아
E(환경)·S(사회) 등급을 개별적으로 더 파고들었다. 코드는 `eda_credit_risk/run_es_industry_eda.py`,
데이터는 `eda_credit_risk/merged_esg_credit_REAL_with_sector.csv`.

- **E·S 등급별 위험징후 비율도 전체 ESG등급과 같은 역방향 패턴**: 환경 A등급 46.4% vs D등급 30.4%,
  사회 A등급 40.9% vs D등급 31.0%(둘 다 등급이 좋을수록 위험징후 비율이 오히려 높음). (`chart3_ES_stage_REAL.png`)
- **E·S·G를 동시에 투입한 로지스틱회귀에서 환경(E)만 유의하게 생존**: 환경_ord 계수 +0.320
  (p=0.001), 사회_ord +(-0.063, p=0.436, 비유의), 지배구조_ord (-0.036, p=0.584, 비유의),
  log_capital -0.147(p=0.001). 즉 이전에 관찰된 "ESG등급 종합점수가 신용위험과 역상관"이라는
  신호는 사실상 **환경(E) 등급이 주도**하고 있고, 사회·지배구조는 환경과의 상관관계 때문에
  단독으로 봤을 때만 유의했던 것으로 보인다.
- **업종별로 나누면 방향이 갈린다** (KSIC 중분류 기준 업종 대분류 버킷, 규모 통제 편상관, `chart4_ES_by_industry_REAL.png`):
  - 제조업(n=625), 금융보험(n=113), 도소매(n=76): E·S 모두 양(+)의 편상관 — 역방향 패턴이 재현됨
    (금융보험은 사회 r=0.260로 가장 강함)
  - 정보통신(n=74): E·S 모두 음(-)의 편상관 (E r=-0.159) — 여기서는 오히려 "정상적" 방향(등급이
    좋을수록 위험 낮음)이 나타남
  - 전문과학기술(n=40): 거의 0에 가까운 약한 양(+)
  - 표본 전체에서 관찰된 역상관은 업종에 관계없이 균일한 현상이 아니라, 표본의 다수를 차지하는
    제조업·금융보험·도소매가 주도하는 것으로 보임 — 업종 구성 자체가 교란요인일 가능성 존재
- **데이터 처리 상 주의사항**: `induty_code`는 고정 5자리가 아니라 기업마다 자릿수가 다른 KSIC
  코드 원본이 그대로 들어있어, 앞자리를 0으로 채우면(zfill) 업종 대분류가 틀어진다. 문자열
  그대로 앞 2자리를 잘라야 올바른 중분류가 나온다(`run_es_industry_eda.py` 상단 주석 참고).

## 3-2. 후속 EDA ② — G등급×이사회 구성 분석 (완료, 2026-08-24)

G(지배구조)등급이 실제 이사회 구성(사외이사 비율)을 반영하는지, 그리고 이사회 독립성 자체가
신용위험과 관계있는지 검증. DART "독립(사외)이사 및 그 변동현황" API(`outcmpnyDrctrNdChangeSttus`)로
E·S 분석과 동일한 1,025개사 표본의 이사 총수·사외이사 수를 수집(1,021개사 성공, `collect_6_board.py`),
KCGS G등급·신용위험 데이터와 병합(n=1,008, 이상치 1건 제외 — 대동전자는 사외이사수>이사총수로 나온
공시 오류로 판단해 분석에서 제외). 코드: `eda_credit_risk/run_g_board_eda.py`,
데이터: `eda_credit_risk/board_composition_RAW.csv`, `merged_esg_credit_board_REAL.csv`.

**핵심 발견 — 이전 두 축(전체 ESG, E·S)과 다른 결과**:

- **G등급은 실제 이사회 독립성을 상당히 잘 반영한다**: G등급↔사외이사비율 Spearman rho=0.47
  (p≈1.1e-56), 규모(자본총계) 통제 후에도 편상관 r=0.29로 유지. D등급 평균 사외이사비율 36.9%
  →A+등급 71.1%로 등급이 오를수록 단조 증가(`chart5_G_board_REAL.png`). 지금까지 본 ESG하위지표
  중 유일하게 "등급이 실제로 측정하려는 것을 잘 측정하는" 결과 — 구성타당도(construct validity) 지지.
- **다만 사외이사비율 자체가 신용위험을 낮추는 신호는 아니다**: 사외이사비율↔risk_score 단순
  상관은 약하고 비유의(rho=0.056, p=0.075). 그런데 규모를 통제한 로지스틱회귀
  (distress ~ outside_ratio + log_capital)에서는 오히려 **사외이사비율이 유의하게 양(+)**
  (계수 +1.276, p=0.006) — 규모를 통제하니 이전엔 안 보이던 역방향 신호가 드러남. 정상군 대비
  위험징후 이상군의 평균 사외이사비율이 43.5% vs 45.3%로 소폭 높음(Mann-Whitney p=0.061,
  경계선상 비유의) (`chart6_board_by_distress_REAL.png`).
- **종합 해석**: 앞선 ESG종합·E·S 분석과 결이 일치하는 결론 — KCGS 등급 체계는 "측정하려는 지배구조
  속성 자체는 비교적 타당하게 측정"하지만(G등급↔실제 이사회 구성 상관 확인), 그 속성이 "낮은
  신용위험"으로 이어진다는 전제는 이 표본에서 지지되지 않는다. 즉 문제는 KCGS 등급의 측정 오류가
  아니라, ESG 우수성과 신용 건전성 사이의 인과·상관 관계 자체에 있을 가능성이 높음(규모 편향,
  업종 구성, 혹은 실제로 사외이사 비율이 높은 대기업이 공시·감시가 많아 위험징후가 더 잘
  '발견'되는 관측 편향 등 — 다음 단계 참고).

## 4. 후속 연구

1. 다년치 PIT 재무제표 패널 구축 후 시차구조 검증 — 등급이 위험을 선행하는지, 위험이 등급에
   반영된 결과인지 시간 순서 분리
2. 기업 규모를 업종 내 분위 등으로 더 정교하게 통제해 "역상관 실재" vs "규모/관측 편향" 재분리
3. HD현대미포·HD현대인프라코어 등 '폐업' 오분류 의심 사례 DART 개별 조회로 검증, 3,806개사 전체에
   유사 사례 있는지 점검
4. 신용평가 3사 등급변동 이력(유료) 확보 시 본 분석과 비교
5. '위험징후' 판정 자체가 공시·감시 강도(대기업일수록 재무 이슈가 더 잘 포착됨)에 좌우되는
   관측 편향인지 검증 — 만약 그렇다면 ESG등급이 높을수록 위험'징후'가 많이 '보이는' 것이지
   실제 신용도가 낮은 게 아닐 수 있음 (G-이사회 분석에서 처음 제기된 가설)
6. 정보통신 업종만 역방향 패턴이 재현되지 않은 이유 규명 — 업종 특성(자산경량화·낮은 부채비율
   구조 등) 때문인지 표본 특이성인지 확인
