# 가설: ESG펀드 보유기업의 신용등급 강등이 펀드 성과에 영향을 미치는가

담당: hewonjin

## 1. 가설

ESG펀드가 보유한 채권 발행기업의 신용위험이 실제로 상승(등급 강등·스프레드 확대 등)할 때,
그 영향이 펀드의 실제 성과(기준가·수익률)에 반영되는지를 검증한다.

포트폴리오 리스크 스코어 = Σ (보유종목 비중ᵢ × 종목별 리스크스코어ᵢ)

## 2. 필요 데이터

| 데이터 | 출처 | 상태 |
|---|---|---|
| 채권 거래량·수익률 | KRX Open API (`bnd_bydd_trd`) | ✅ 확인 완료 |
| 재무제표·부도/회생 이벤트 | DART Open API | ✅ 확인 완료 |
| 펀드 자산구성내역 | FUND DART | ⏳ 확인 중 |
| 펀드 기준가(NAV)·수익률 | FUND DART / 제로인 / 에프앤가이드 | ⏳ 확인 중 |

## 3. 검증 방법

1. 분석 대상 펀드의 보유종목 중 실제 신용사건이 발생한 종목 식별
2. 사건 전후 포트폴리오 리스크 스코어 변화 확인
3. 같은 기간 펀드 실제 기준가·수익률 변화와 시차(선행/후행) 비교
4. 보유비중별 대조군 비교로 '비중이 클수록 영향도 큰가' 확인

`common/analyze_divergence.py`의 이벤트 스터디 구조를 재사용.
