## 1. 원 가설

ESG펀드가 보유한 채권 발행기업의 신용위험이 실제로 상승(등급 강등·스프레드 확대 등)할 때,
그 영향이 펀드의 실제 성과(기준가·수익률)에 반영되는지를 검증한다.

포트폴리오 리스크 스코어 = Σ (보유종목 비중ᵢ × 종목별 리스크스코어ᵢ)

### 필요 데이터 (원 가설 기준)

| 데이터 | 출처 | 상태 |
|---|---|---|
| 채권 거래량·수익률 | KRX Open API (`bnd_bydd_trd`) | ✅ 확인 완료 |
| 재무제표·부도/회생 이벤트 | DART Open API | ✅ 확인 완료 |
| 펀드 자산구성내역 | FUND DART | ❌ 확보 불가 (막힘) |
| 펀드 기준가(NAV)·수익률 | FUND DART / 제로인 / 에프앤가이드 | ❌ 확보 불가 (막힘) |

펀드 관련 두 데이터는 끝내 실제 소스를 구하지 못해, `esg_fund_credit_hypothesis.ipynb`
(로컬 `C:\hewon\Team_project`)에서는 합성(시뮬레이션) 데이터로 파이프라인만 시연해둔 상태.
**신용위험 사다리(정상→위험징후→신용등급하락→부도) 자체는 DART 실데이터**이고, 합성인 건 어느
펀드가 어느 기업을 얼마나 들고 있는지·기준가뿐 — 이 구분을 헷갈려서 한 번 폐기했다가 되살린
해프닝이 있었음(과정은 원본 세션 기록 참고).

## 2. 재정의한 가설 — ESG등급이 신용위험과 실제로 연결되는가

### 데이터

| 소스 | 내용 | 표본 | 실제/합성 |
|---|---|---|---|
| KCGS ESG등급 | ESG·환경(E)·사회(S)·지배구조(G) 등급 + 등급조정 이벤트 | 1,091개사 (2025) | 실제 |
| 신용위험 사다리 | 정상→위험징후→신용등급하락→부도, 부채비율·유동비율·자본총계 | 3,806개사 | 실제 (`credit_stage_panel.csv`) |
| 조인 결과 | 두 소스를 종목코드로 조인, 등급없음 제외 | 1,025개사 | - |

### 검증 방법

1. KCGS ESG등급(전체·E·S·G) ↔ 신용위험 단계·리스크스코어 순위상관(Spearman), 카이제곱
2. 기업 규모(자본총계) 교란 확인 및 로지스틱회귀로 통제
3. KCGS가 실제 공시한 '등급조정' 이벤트(연중 발생한 거버넌스·사회 리스크로 인한 하향 조정, 53개사)를
   교차 검증 신호로 사용

## 3. 검증 결과

**핵심 발견 — 서로 독립된 두 실제 데이터 신호가 같은 방향을 가리킴**: "ESG등급이 높을수록 신용위험이
낮다"는 단순 가설은 지지되지 않았고, 오히려 반대 방향의 유의한 상관이 반복 관찰됨.

- 우량군(A등급 이상) 위험징후 비율 44.2% vs 비우량군(B+이하) 35.3% (오즈비 1.45, 카이제곱 p=0.017)
- ESG등급 순위상관 vs risk_score: r=0.083, p=0.0077 (환경 r=0.107 p=0.0006, 사회 r=0.073 p=0.019 모두 유의;
  지배구조만 비유의 r=0.048 p=0.126)
- ESG등급은 기업 규모와 강하게 상관(r=0.64, p<0.0001) — 대기업 편향 구조. 다만 로지스틱회귀로 규모를
  통제한 뒤에도 ESG등급 계수는 여전히 유의하게 양(+) (+0.188, p=0.0001) — 규모 편향만으로 완전히
  설명되지 않음
- KCGS 실제 등급조정 이벤트(53개사)에서도 재현: 조정받은 기업의 ESG등급이 오히려 유의하게 더 높음
  (Mann-Whitney p<0.0001~0.01), 조정 안 받은 축으로 교차검증해도 동일 방향
- 심각 신용사건(등급하락·부도, n=10)은 표본이 너무 작아 결론 불가. 그중 2건(HD현대미포·HD현대인프라코어)은
  계열 개편으로 인한 '폐업' 오분류 의심 — 데이터 품질 이슈로 별도 플래그

상세 통계·차트·해석은 `ESG등급_신용위험_EDA_정리본.docx` 참고.

## 4. 후속 연구

1. 다년치 PIT 재무제표 패널 구축 후 시차구조 검증 — 등급이 위험을 선행하는지, 위험이 등급에
   반영된 결과인지 시간 순서 분리
2. 기업 규모를 업종 내 분위 등으로 더 정교하게 통제해 "역상관 실재" vs "규모/관측 편향" 재분리
3. HD현대미포·HD현대인프라코어 등 '폐업' 오분류 의심 사례 DART 개별 조회로 검증, 3,806개사 전체에
   유사 사례 있는지 점검
4. 신용평가 3사 등급변동 이력(유료) 확보 시 본 분석과 비교
